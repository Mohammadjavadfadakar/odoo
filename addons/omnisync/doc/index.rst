Overview
--------
OmniSync is a universal synchronization framework for Odoo 18 Enterprise that enables no-code and low-code integrations with third-party applications. The documentation in this folder is organized to guide administrators, integrators, and operators through setup, configuration, monitoring, and advanced automation scenarios.

Use the sections below to learn how to deploy OmniSync, configure external systems, build synchronization flows, and monitor their execution. Each topic highlights best practices, security considerations, and troubleshooting tips to keep integrations reliable and auditable.
